# Desert Anime Kitchen

This is a top down factory game in Unity 6 where anime girl workers dig up ingredients in a desert and turn them into desserts. Everything happens on a grid. `DesertMap` holds the Unity `Grid` and its tilemaps for the sand, the deposits and the colored deposit outlines. `Factory` tracks which building is on which cell and updates every building each frame. All buildings inherit from `Building`, which handles the footprint, facing direction and passing items to whatever is in front of it. `HarvesterGirl` digs from deposits, `Conveyor` moves items along, `CookGirl` crafts recipes and `DessertStall` sells desserts into the shared `Stockpile`.

Items, deposits, recipes and buildings are defined by ScriptableObject classes in `Assets/Scripts/Data`, and each one is an asset you edit in the Inspector (the test ones are in `Assets/TestContent`), so adding a new ingredient or worker usually means making a new asset, not writing new code. A `GameContent` asset lists everything the game uses; if none is assigned, the placeholder content in `GameContent.CreateDefault()` is used. `GameBootstrap` sets up the map, factory, camera, build controls and the HUD prefab in `Assets/Resources` when a scene starts. Run `Dessert Factory > Build Test Content` from the editor menu to regenerate the test assets, and use `Assets/Scenes/TestFactory.unity` to try things out.
