# Desert Anime Kitchen

This is a top down factory game in Unity 6 where anime girl workers dig up ingredients in a desert and turn them into desserts. Everything happens on a grid. `DesertMap` holds the Unity `Grid` and its tilemaps for the sand, the deposits and the colored deposit outlines. `Factory` tracks which building is on which cell and updates every building each frame. All buildings inherit from `Building`, which handles the footprint, facing direction and passing items to whatever is in front of it. `HarvesterGirl` digs from deposits, `Conveyor` moves items along, `CookGirl` crafts recipes and `DessertStall` sells desserts into the shared `Stockpile`.

Game content is data, not code. Items, deposits, recipes and buildings are ScriptableObjects under `Assets/Scripts/Data`, collected in a `GameContent` asset, so new ingredients or workers can be added in the editor. `GameBootstrap` sets up the map, factory, camera, build controls and the HUD prefab in `Assets/Resources` when a scene starts. To get test assets, run `Dessert Factory > Build Test Content` from the editor menu, and use `Assets/Scenes/TestFactory.unity` to try things out.
